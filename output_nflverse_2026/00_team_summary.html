How the pipeline works

  1. Load and validate any .xlsx (sheet GamePBP) or .csv in the PFF GamePBP layout. Headers are normalized, every column is read as text and converted on purpose, and missing optional columns are reported but don’t stop the run.
  2. Build the sample: one offense, run/pass plays only, downs 1-4, excluding garbage time and QB kneels/spikes. Each filter step is counted in the report.
  3. Analyze the six scouting questions from the prompt (personnel, down and distance, QB alignment, run concepts, third down and targets, player production) plus passing context and pre-snap tells.
  4. Write findings with fixed rules (tendencies, strengths, vulnerabilities), each with its sample size, then render the HTML and PDF reports, the CSV/Excel tables and the PNG charts.
  5. Stress tested on the mock files plus edge-case and regression checks (CSV input, messy headers, multi-team files, missing columns, one game, pass-only and run-only offenses, junk values, config switches).
